## 0. 一句话结论

**训练域 val_auc=0.9758 是"训练域专属捷径 + 听觉监督断裂"叠加的结果，跨域时捷径消失、音频信号又没被训练用上，于是全崩；纯物理（短程运动学）代理经实测同样是生成器专属、不可迁移，方向A被证伪。**

## 2. 数据层 / 身份 / 生成器三重排除（§已闭环）

1. **身份重叠排除**：训练域 220 身份中 217 个含 real+fake，只有 3 个单标签 → **认身份 ≠ 给标签**。
2. **样本泄漏排除**：三评测集与训练集身份/样本重叠 = 0 → **无数据泄漏**。
3. **预处理一致**：`audio_seq / v_clip / v_lip` 维度各集一致 → **非预处理不一致**。
4. **FakeAVCeleb 极端不平衡**：real=178 / fake=19547 → 其 **AP/ACC 虚高、无信息量**，只信 AUC。
5. **HiFi 组内生成器**：seedance1.0/sora2/veo3.1/pixverseV5/wan2.5/kling2.5 组内 AUC 0.39–0.60
   → **换生成器即崩**（跨生成器泛化问题是主因，非单集噪声）。

## 3. 模态消融（mask）—— 定位"哪条监督断了"

口径备忘（反直觉，勿踩）：`--mask audio`=保留视觉(video-only)；`--mask visual`=保留听觉(audio-only)。
评测均在 DeepSpeak 训练域，用 `syncx_best_seed0.pt`：

| 模态 | AUC | 判读 |
|------|-----|------|
| 全模态 | 0.9758 | 基准 |
| video-only (`--mask audio`) | 0.9873 | 视觉即可满分 → 视觉表征绑训练域（作弊分，不用救） |
| audio-only (`--mask visual`) | **0.5197** | 听觉几乎随机 → **听觉监督断裂**，这是要救的指标 |

结论：模型强依赖视觉；音频分支缺乏对 real/fake 的直接监督。

## 4. 音频探针 vs 融合对照 —— 瓶颈在监督，不在特征/融合

- **探针**：`audio_emb` 线性探针 AUC=0.827，但 |Δ质心|=0.044（弱可分）→ **音频特征有信息，但被监督丢弃**，断裂在监督/下游而非特征。
- **融合对照（1c）**：关闭 DWF、改固定 0.5/0.5 平均融合，audio-only 仍 **0.5184** → **证伪"融合吞音频"**，瓶颈在监督本身。
- **v2 模块1 修正后**：audio-only 0.5197→0.5734（独立音频头）/0.5252（融合头），**仍未达 >0.8**；跨域融合头几乎不动。

## 5. 训练域捷径扫描（diag_shortcut.py cache，每类上限 800）

口径：`auc(实0)`（real=0 计分，>0.5 表示 real 特征更高）；`strength=max(auc,1-auc)`；
`cohen_d`（+ = real 更大）。

### 5.1 训练域 DeepSpeak train（real=5251 / fake=5299）

| 特征 | strength | cohen_d | 判定 |
|------|----------|---------|------|
| 音频开头8帧能量比 | 0.559 | +0.199 | 无前导静音 |
| 音频序列整体能量 | 0.504 | +0.008 | 无 |
| 音频前1/3段能量比 | 0.510 | +0.044 | 无 |
| 视觉帧间运动量 | 0.630 | +0.447 | ▲中等 |
| 视觉帧间运动量标准差 | 0.655 | +0.315 | ▲中等 |
| **landmark 时域抖动** | **0.738** | **-0.855** | ★最强(fake 更抖) |
| landmark 幅度RMS | 0.514 | -0.080 | 无 |

- **音频侧零捷径**（DeepSpeak 无 FakeAVCeleb 那种 leading-silence bias）。
- **没有单特征能独力刷到 0.97**（最强仅 0.738）→ 训练域"白捡捷径"不强，不能单独解释同域 0.97；
  0.97 更可能是多源域指纹叠加。

### 5.2 跨生成器迁移性（同脚本，三跨域集）

| 集 | landmark 时域抖动 | 视觉帧间运动量(std) | 结论 |
|----|------------------|---------------------|------|
| FakeAVCeleb | 0.626 (d=+0.462) | 0.665/0.654 (d=-0.6) | fake 反而**更不抖**，方向翻转 |
| DFE2024 | 0.544 (d=+0.154) | 0.511/0.502 | ≈随机 |
| HiFi-AVDF | 0.524 (d=-0.023) | 0.506/0.516 | ≈随机 |

**定论**：训练域那个 d=-0.855 的强抖动信号是 **DeepSpeak 生成器专属捷径**，**跨生成器不迁移**
（HiFi/DFE 全≈随机，FakeAVCeleb 还方向翻转）。

## 6. 物理代理失败（diag_physics_probe.py，方向A证伪）2026-08-21

把"高阶运动学"从统计升级为物理代理（S-G 平滑导数 jerk 的 mean/p95/max/kurtosis/能量比），
核长恒=窗口（自包含 `_sg_coeffs`），看是否满足"物理边界可跨生成器迁移"。

| 集 | lip_jitter(对照) | jerk_mean | jerk_max | jerk_kurtosis | jerk_pos_energy_ratio | 判定 |
|----|------------------|-----------|----------|---------------|----------------------|------|
| DeepSpeak train | 0.738 (d=-0.86) | 0.757 | 0.786 | 0.790 | 0.776 | 同域强(仅参照) |
| FakeAVCeleb | 0.626 (d=+0.46) | 0.637 | 0.657 | 0.643 | 0.647 | ⚠️ 假阳性 |
| DFE2024 | 0.544 | 0.552 | 0.539 | 0.528 | 0.539 | ≈随机 |
| HiFi-AVDF | 0.524 | 0.529 | 0.525 | 0.517 | 0.528 | ≈随机 |

**三条硬证**：
1. **短程高阶运动学(jerk 族)跨生成器不可迁移**：DFE2024、HiFi 全 ≈0.5。
2. **方向符号不稳定是铁证**：训练域 `cohen_d` 全负（fake 抖动更大），FakeAVCeleb 翻正
   → 同一代理不同生成器符号反转，证明是**生成器专属伪影、非物理不变约束**。
3. **FakeAVCeleb 的 ~0.64 是红鲱鱼**：real 仅 178、方向还与训练域相反，不作证据。

**→ 方向A（纯短程运动学物理代理）关闭。** 下条实物验证转向方向B（频域/长时域/时序连贯）。

## 6B. 方向B 前置探针 · 频域/时序/音画相干 跨生成器可分性（未过门）2026-08-21

`diag_freq_probe.py cache`（每类上限 800），候选代理=视觉低频能量占比 / 颌动自相关(AC1,AC2,AC10) /
音频包络低频占比 / 音频包络自相关(AC1) / **音画交叉谱相干(sync_corr_1to8Hz，红线核心)**。

| 集 | motion_lowband | motion_AC1 | motion_AC2 | audio_env_AC1 | sync_corr_1to8Hz |
|----|----------------|------------|------------|---------------|------------------|
| DeepSpeak train | 0.629 | **0.740** (d=+0.98) | 0.722 | 0.524 | 0.507 |
| FakeAVCeleb | 0.574 | 0.619 (d=-0.53) | 0.606 | 0.624 | 0.521 |
| DFE2024 | 0.543 | 0.534 | 0.525 | **0.649** | 0.504 |
| HiFi-AVDF | 0.553 | 0.517 | 0.521 | 0.547 | 0.508 |

**判读（与方向A 同一判据）**：
1. **红线核心 sync_corr_1to8Hz 四集全 ≈0.5，连训练域都不可分** → 用「wav2vec2 能量包络 × 颌动均值」
   这个粗代理，音画相干信号在 1–8Hz 带**根本不被特征捕获**（代理口径局限，也可能是该粒度确无信号）。
2. **motion_AC1**：训练域 0.74 但**跨集符号翻转**(train +0.98 / FakeAVCeleb −0.53)、DFE/HiFi ≈0.52
   → 与方向A 的抖动一样是生成器专属，**不迁移**。
3. **audio_env_AC1**：唯一在 DFE 到 0.649，但 train 仅 0.524、HiFi 0.547，**不单调、不稳**，
   且是**单模态音频平滑度**（非跨模态）→ 不作立项证据。

**定论：方向B「粗代理跨生成器可分」未过门，FTA 架构不落地**（避免再次把重训烧在不可迁移代理上）。

**关键洞察（指向真正的路）**：此前 `audio_emb` 线性可分 0.827，证明**可分信号在音频"内容"特征
(wav2vec2 深层)，不在能量包络/运动学/相干等"结构代理"**。本轮三大路线(短程物理/频域/相干)全死于
"够不着那个内容可分信号"。故最优解不是再造代理，而是**训练配方侧**：让模型把早已可分的音频内容
特征真正逼出来用——见 `module2_directionB_plan.md` 转向"监督侧"(Stage-2 冻结编码器 / modality dropout / 强音频监督)。

## 7. 附带发现的实现 bug（留待重训时一并修）

- `models.py` `savgol_coeffs`：`x = np.arange(-window // 2, window // 2 + 1)` → `(-window)//2` 地板除
  使核长=window+1。`Kinematics` 默认 window=7 实际算出 **8 点窗**（conv1d kernel=8，非文档 7）。
  - 属**静默行为偏差**；改它会让已有训练权重的 Kinematics buffer 张量失配 → **必须换架构重训时一并修**，
    不得热改旧权重。
  - 探针版 `diag_physics_probe.py` 已用 `np.arange(window)-(window//2)` 修掉（核长恒=window）。
- **v2-1a 引入的 disable_lcma 回归（2026-08-21 冒烟时撞到，未修，与方向B 无关）**：
  `disable_lcma=True` 时 forward 走 `audio_emb = h_laca_bi`（形状 2d=512），但 `audio_aam` 头只接受
  d_model=256 → 推理/训练都会 `RuntimeError: mat1 4x512 and 256x2`。主线（disable_lcma=False）不受影响；
  只有 w/o-LCMA 组件消融会踩。若日后要跑 w/o LCMA 消融，需先把 disable_lcma 分支的 audio_aam 输入
  修正为 d_model 维（或降级该分支 audio_aam）。方向B 冒烟因此改为直接测 DWF 三路零占位、绕过此 bug。

## 8. 最终根因整合（为什么跨域会崩）

| 现象 | 解释 |
|------|------|
| 同域 0.9758 | 靠"训练域专属运动/抖动指纹 + 视觉域指纹"叠出来 |
| 跨域 0.47–0.55 | 目标域没有这些指纹 → 直接失效 |
| audio-only 0.52→0.57 | 训练从未逼模型学"音频真伪"（断裂在监督）；探针 0.827 证明信号存在但没用上 |
| 模块1 加音频头只 +0.05 | 加的是凑数弱分类器，捷径仍主宰最优解 |
| 物理代理不肯迁移 | 连物理量都是生成器专属 → 纯物理路线断 |

**两件事叠在一起才是全貌**：
- **A. 听觉监督断裂**（可修）→ 音频已含可分信息(0.827)却没被训练利用。
- **B. 视觉/运动学表征过拟合训练域**（难修）→ 换生成器即崩，且短程物理代理也不迁移。

**后续方向**（均在 Cross-Modal 红线内）：方向B = 长时域 + 时序连贯 / 频率增强分支，目标是
把"跨生成器不变"的信号（频谱结构、长程时序规律、音画交叉谱相干）逼出来用到判伪上；
并配以 modality dropout 防单模态域捷径（训练伴项）。

## 8B. 监督侧·冻结编码器（Stage-2 freeze）实测负结果 2026-08-21

**做法**：`SYNCX_FREEZE_ENCODER=1` + `SYNCX_MODAL_DROPOUT=0.3` + 修 `savgol_coeffs` 地板除 bug 后重训
（Stage-1 新架构重训 60ep → Stage-2 冻结 `lcma.*`/`laca.*` 只训 DWF/AAM/audio_aam）。

**关键启动态**：`FREEZE encoder ON：可训练 3586 / 5054274 参数`，双 `loaded stage1 LCMA/LACA: All keys matched successfully`
（7 点窗新架构与 Stage-1 完全对齐，savgol 修复无加载失配）。

| 指标 | 上轮(全量微调 v2) | 本轮(冻结 Stage-2) |
|---|---|---|
| train 域 val_auc | 0.973 | **0.874（epoch 77–80 平台死)** |
| FakeAVCeleb | 0.6187 | **0.4373（反向下探)** |
| DFE2024 | 0.535 | 0.441 |
| HiFi-AVDF | 0.4735 | 0.4592 |

**定论：冻结编码器路线双输，否决。**
- train 从 0.97 → 0.874 且平台卡死：只训 3586 融合头参数，从冻结特征**榨不出满血分类力**。
- 跨域不升反降(FakeAVCeleb 甚至 0.437 反向)：冻结锁死了骨干，也没把任何可迁移信号带出来。
- 归因注意：本轮 freeze 与 modality-dropout 同开，数字是叠加态，不能单独归因其一；
  但主因明显是 freeze（train 平台 0.874 即证据）。**教训：change 一次只动一个变量，否则归不了因。**

**→ 下一轮若再走训练配方侧，应否 freeze，改走「部分冻结」或「只重训练音监督」并单变量验证。** 见 §10。

## 8C. 监督侧·仅冻视觉支路（FREEZE VISUAL-ONLY）实测负结果 2026-08-21

**做法**：单变量（与 §8B 互斥，未开 modality dropout）——`freeze_visual_only=1` 冻结视觉支路
（`lcma.visual_proj` + `laca` 唇部运动学 kin_mlp/kinematics/gru/biomech/lip_shared_proj），
放开 `audio_proj` / 双 shared_proj / corr / fuse / DWF / AAM / audio_aam 头。

**动机**（承接 §8B）：全冻结把 train 平台卡死 0.874 且跨域反向，故只冻视觉、逼训练真正用上
`audio_emb` 的可分信号（证据链 §4：audio 探针 0.827 可分）。

**关键启动态**：`FREEZE VISUAL-ONLY：冻结视觉支路，放开 audio/fusion`（实测日志确认已触发）。

**实测评测（STEP 5，seed0，12:00 时段重跑）**：

| 指标 | 全量微调 v2 | 全冻结(§8B) | **仅冻视觉(本轮)** |
|---|---|---|---|
| FakeAVCeleb | 0.6171 | 0.4373 | **0.5189**（AP 0.9908，只信 AUC）|
| DFE2024 | 0.5506 | 0.441 | **0.5558** |
| HiFi-AVDF | 0.499 | 0.4592 | **0.4975** |

**定论：仅冻视觉路线同样不成立，训练配方轴三连负，正式关闭。**

- **与证据链 §4 完全自洽**：单独 audio-only 在训练域本就只有 ~0.52（几乎随机）。本轮把视觉支路冻死、
  逼模型靠 audio 分支 → 训练域那条本就微弱的音频信号不够用，**唯一剩下的一点赞助性可迁移线索本在视觉侧，
  冻结 = 自废**。FakeAVCeleb 从 0.6171 退到 0.5189 完全解释得通。
- DFE 0.5558 / HiFi 0.4975 依旧贴地，三方案没有一条打进 >0.6 区间。

**归因上移（关键结论）**：全量 / 全冻结 / 仅冻视觉三条配方，全都在**同一组离线冻结特征
（CLIP-ViT-B/16 + wav2vec2-base-960h）+ 不同训练法**上打转，跨域全 ≈随机。
→ **瓶颈根本不在"监督 / 融合 / 冻结策略"，而在更上游的离线特征表征层本身跨生成器不可迁移。**
再开第 4 个训练配方（换 loss / 调冻结）也是在同一根棍子上换握法，不会突破 0.6。

**→ 训练配方轴弃用。下一步换成输入/特征轴，正式立项方向B（长时域 + 频率增强分支）**，
从输入侧引入更长时序上下文与更鲁棒声学/运动学表征，而非继续在既有特征上折腾监督。见 `module2_directionB_plan.md`。

## 8D. 方向B（LTCA）首次实测：部分成立，DFE 首次顶过 0.55（2026-08-21）

**做法**：`module2_directionB_plan.md` 重定义方向B = **内容特征长时一致性适配器（LTCA，第三分支）**，
彻底删掉被 §6B 证伪的结构谱子路。LTCA 输入服用 LCMA post-attention 内容嵌入 `a_seq/v_seq`：
子系统A（audio/visual 各一条 dilated temporal conv 1,2,4 + 池化 MLP）+ 子系统B（vis-attend-aud cross-attn
+ 显式时序相干标量）。DWF 扩三路门控（偏置 favour LCMA→LACA→FTA）。`SYNCX_FTA=1` + 全量微调。
红线自查：LTCA **无纯单模态路径**（子系统A 即双路拼接），物差开发时冒烟全绿。

**关键交付链（防再踩实坑）**：本地改好 LTCA 后必须打包覆盖云端 `code_cloud/`（正斜杠 zip，
arcname 裸文件名 `unzip -o x.zip -d code_cloud/`），并在启动前核验版本
`grep -n "class LTCA" models.py`。本地改不传云端 = 云端跑旧模型（`fta_enabled=None`、无 `fta.*` 键），
表现为"val 掉却评测出旧分"。本次踩了 4 轮才首次让 `fta_aud_conv=6`（LTCA 权重）写进 `syncx_best_seed0.pt`。

**启动实锤（训练中途 resume 取证）**：`fta 键数= 24`，示例 `fta.aud_conv.0/2.weight/bias` →
LTCA 分支真实训练、真实落盘；`最后训到 10/80 val_auc=0.9462`（train 域不塌）。

**实测评测（STEP 5，seed0，17:4x）——方向B 三集：**

|--------|-------------|------------|---------------|----------------|
| FakeAVCeleb | 0.6171 | 0.4373 | 0.5189 | **0.6009** |
| DFE2024 | 0.5506 | 0.441 | 0.5558 | **0.5796** ↑ |
| HiFi-AVDF | 0.499 | 0.4592 | 0.4975 | **0.4834** ↓ |

**判定：方向B 部分成立。**
- **DFE2024 0.5796 首次顶过 0.55**：四条配方里唯一把"中等跨域集"真正推过 0.55 的——`内容长时一致性`
  在 DFE 上带来了**可检测的真实可迁移增益**（之前三条配方 DFE 最高仅 0.556）。
- **FakeAV 0.6009** 较 v2 微降 0.016（正常抖动，未以崩盘为代价），守稳 0.60。
- **HiFi 0.4834 反降**是软肋：HiFi（5 个 SOTA 生成器、最严苛、最依赖音画一致性）上 LTCA 的 sync 项
  没带来增益、甚至微伤 → **整体三集加总仍不如 v2**。

**待办（§10 导向）**：方向B 证明了"内容长时一致性"能跨域提分，但深入 HiFi 才成立。
下一步单变量排查 HiFi 软肋：① 子系统B sync 标量是否拖累 HiFi（`--fta_no_sync` 对照）；
② 是否需给 HiFi 更长的时序窗 / 更强的音画相干监督（当前靠分类隐式学、L_sync 默认关）。

## 8E. 方向B · HiFi 软肋单变量排查：sync 标量**不是**负迁移源（2026-08-21 晚）

**背景**：§8D 待办假设"HiFi 反降可能归罪于 LTCA 子系统B 的 sync 标量"。调研确认 HiFi 假视频
是 Sora2/Veo3.1/Seedance/Kling/WAN/PixVerse 六个 SOTA 生成器 **T2V/I2V 端到端一体生成**、音画天然
同步、lip-sync 高度成熟（HAVIC 论文原话："lip-sync defense is being systematically dismantled"）→
推测 sync 项在 HiFi 无可分信号、负迁移。**本轮用方向B ckpt 直接实测，结果推翻该假设。**

**新增交付物**（只推理、不改训练不改权重）：
- `diag_sync_t.py`：加载方向B ckpt，复用模型前向，抽 LTCA 真实内部标量
  `sync_t = mean_t cos(a_seq[t], v_seq[t])`，测四个集 real/fake 可分性。
- `evaluate.py --fta_no_sync`（+ `config.fta_no_sync` / `models.LTCA.forward no_sync` 三处接线）：
  评测时跳过子系统B，只留长时骨干 h_long，measure 去 sync 后 AUC 是否变化。

**sync_t 可分性实测（探针，seed0，max_per_class=600，另见 diag_sync_t.py 交付物）：**

| 集 | sync_t strength | cohen_d | 判读 |
|----|-----------------|---------|------|
| DeepSpeak train | **0.755** | **-0.725** | 训练域专属；**fake 同步反而更高** |
| DFE2024 | **0.508** ≈随机 | +0.031 | 随机——但 DFE 却是提分最多(0.5796)的集 |
| HiFi-AVDF | **0.580** ≈随机 | -0.254 | 随机偏弱——但关掉 sync 后 HiFi 反降 |

**对照评测（HiFi，`--fta_no_sync`）：**

| HiFi-AVDF | AUC | Δvs 方向B全开 |
|-----------|-----|--------------|
| v2 全量（基线） | 0.499 | — |
| 方向B（LTCA 全开） | 0.4834 | — |
| 方向B 关 sync（只留 h_long） | **0.4735** | **再降 0.010** |

**四条新证据（关键在 2 与 4 的不对称）：**
1. **关掉 sync 项，HiFi 不回升反再降 (0.4834→0.4735)** → **sync 标量不是 HiFi 负迁移源**，反而略有正贡献。
   原假设（§8D 待办①）**证伪**。
2. **DFE 的 sync_t 是随机的 (0.508) 却提分最多 (0.5796)** → DFE 增益**必来自 LTCA 的 h_long 长时骨干 /
   cross-attn 特征，而非显式 sync 标量**。方向B 在 DFE 的有效成分是"长时内容骨干"，不是 sync。
3. **train 域 sync_t 可分 (0.755) 但符号为负 (cohen_d=-0.725)** → fake 同步程度比 real 更高，又一条
   "训练域专属、跨集翻转/消失"的指纹（与 §5 landmark 抖动同构）→ sync 标量本质也是 DeepSpeak 生成器专属伪影，
   反而在 HiFi 有 +0.010 微小正贡献。
4. **组合归因（最重要）**：既然 sync_t 在 HiFi 上 ≈随机 (0.580)、关 sync 反降——说明 HiFi 亏在「关掉 sync 后
   只剩 h_long」这一倒序里，**真凶是 h_long 长时骨干本身**：它把 DeepSpeak 域专属的时序演化指纹带进来，
   在 HiFi（端到端一体生成）上不迁移、甚至反向；而子系统B 的部分（cross-attn / sync）恰是"通用相干"、尚能在
   HiFi 补 +0.010。这与红线命题相反但诚实：**是"长时内容骨干"负迁移，不是"音画相干"负迁移**。

**判读**：方向B 的 DFE 增益可迁移成分 = h_long 长时内容骨干（子系统A）；HiFi 软肋 = 同一 h_long 骨干带 DeepSpeak
时序指纹。sync 子系统B 在 DFE 无增益、HiFi 微正，既非元凶也非救星。整体回到 §8C 归因上移：瓶颈仍在离线特征
表征层跨生成器不可迁移，LTCA 只能把可分信号在更长时序里重复利用，造不出"跨生成器不变"的强信号。

**待办（收紧）**：既然 HiFi 反降主因是 h_long 骨干，下一步：
① 测 **w/o 整个 FTA 第三分支**（`SYNCX_FTA 权重归零 / 关 DWF 三路回两路`）在 HiFi/DFE 对照，锚定"第三分支整体"贡献；
② 若 h_long 确认负迁移 → 方向B 收敛为「保留 DFE 增益 + 接受 HiFi 贴地」的诚实部分结果，或给 h_long 加跨域正则/权重衰减。
两个方向都不必重训（现有 ckpt 即可做 w/o-FTA 评测），单变量。未用 Explore 子代理（本轮为本地推理探针）。

## 8F. 特征层调研：AV-HuBERT / 一致性先验 / ROGA 现状（2026-08-21，决策依据）

**背景**：§8C 归因上移"瓶颈在特征表征层"，方向B（LTCA）只把可分信号长时复用、造不出跨生成器
不变信号。本节为"是否换音频编码器 / 加跨域正则"做文献核实，用 3 个只读 Explore 子代理交叉调研。

**AV-HuBERT 核实结果（含关键反转）：**
1. **换 AV-HuBERT 大概率不是银弹**：SSR-DFD(CVPR2026) 系统测得的纯音频跨域检测里，wav2vec2 在
   DFE-2024 达 96.6，反而高于 AV-HuBERT(V)=64.1、AV-HuBERT(AV)=94.5 → **wav2vec2 本身是强编码器**。
   "特征绑训练域"不是编码器性能问题，是下游监督/域微调问题，甩锅编码器无效。
2. AV-HuBERT 真正有价值的点 = 它的**跨模态对齐表征**（AV-Lip-Sync+ 用它同时抽 audio+visual 唇部特征、
   FakeAVCeleb SOTA），不是替换 wav2vec2 当音频编码器。
3. **License 坑**：Meta 专属协议（非 Apache/MIT）；HuggingFace 只有第三方 MuAViC 封装(CC-BY-NC)。
4. Pascu et al.(2023) 冻结 wav2vec2 大模型 + 逻辑回归，8 个 out-of-domain 集 EER 30.9%→8.8% → 编码器
   跨域下限不差，印证"问题在训练监督/生成器捷径，不在编码器"。

**对策"端到端生成视频音画一致"的最新文献（对 HiFi 软肋的最有价值信息）：**
- HAVIC(CVPR'26 Findings)：先在**真实视频**上预训练"音画内在一致性先验"(micro/macro coherence)再检测；
  跨数据集 AUC 提升 ~9.4%。**最贴红线**，也最能解释 HiFi 差距——我们的训练一致性来自 DeepSpeak(生成器
  专属)，缺"真实世界一致性"作锚。
- X-AVDT(CVPR'26)：潜入**生成器内部 audio-visual cross-attention** + DDIM inversion 检测；对端到端生成
  原理最对症。
- CMTA/DVF(MM-Det)：从低层同步升级到**音-视-文语义时序稳定性**/多模态 LMM 表示，提升扩散视频检测泛化。
- BioLip(2026)：唇部运动学受肌肉/神经带宽约束，在"纯换脸/纯唇改"上高达 0.9+ → 印证物理线索对部分
  生成器强、对"整段一体生成"失效（与方向A 死法一致）。

**判读**：HiFi 上 0.48 不是"音画一致性死了"，而是"训练域一致性 = DeepSpeak 生成器专属"。要走通，
**换编码器无效（.## wav2vec2 已强）**；有效的是换"一致性源头"（真实数据先验，仿 HAVIC）或"潜入生成器
内部"（仿 X-AVDT，对端到端最对症）。

**中等成本路线立项（本节选）**：给 Stage-2 加 ROGA 式跨域梯度对齐或一致性先验正则，检验 h_long 是否
能收敛到"生成器无关"。因训练仅 DeepSpeak 单域，ROGA 式"跨域梯度对齐"需构造多"域"视图（见 §8G 方案）。
未用更多子代理，本节为综合判读。

## 8G. 【根因升级】跨域评测集特征"音画时间窗错位"——比生成器差异更早更硬（2026-08-21 深夜）

**触发**：方向B no_sync 对照反降后，回看特征抽取，发现训练域与跨域评测集 prep **不一致**。

**铁证（人工比对 4 个 prep.py + 时长实测）**：

| 数据集 | prep 抽样方式 | 音频抽取 | 时间轴 |
|--------|--------------|---------|--------|
| DeepSpeak(训练域) | `clip_center_window(vid,4,25)` + `sample_frames(window_sec=4)` | `video_to_wav(ss,td)` | **中心 4s 窗，音画严格对齐** ✓ |
| HiFi / DFE2024 / FakeAV(跨域) | `sample_frames(target_count=100)`（**无 window_sec = 整段均匀**) | `video_to_wav(无 ss/td)`（**前 4s**） | **视频整段 vs 音频前4s → 错位** ✗ |

即：跨域评测集**视频特征覆盖全程、音频特征只覆盖前 4 秒**，时间轴不一致 → sync_t /
cross-attn / LTCA 在音画序列间算一致性时**机制上被打乱**。

**时长实测（本地 diag_clip_duration.py，>4s 占比 = 错位影响面）**：

| 集 | 总视频 | >4s 占比 | 中位时长 |
|----|--------|---------|---------|
| HiFi | 3810 | **99.6%** | 5.92s |
| DFE2024 | 2036 | **99.0%** | 40.3s |
| FakeAVCeleb | 7472 | 74.8% | 4.60s |
| DeepSpeak(对照) | 13463 | 90.3% | 7.1s |

**关键洞察**：训练域也 90% >4s，但它靠 `clip_center_window(4s)` **把音画同时截到同一中心窗** → 对齐。
所以"长"不是错位原因，**"prep 有没有做锯口截取"才是**。跨域集 prep 漏了这一步。

**易碎点/防误判**：
- cache.pt 断点续跑会**跳过已存在** → 改 prep 后须强制删旧 cache 重抽，否则白跑。
- HiFi/DFE 直接 `rm -rf prep` 即可；**FakeAVCeleb 的 prep/ 内含 B6 探针产物**(b6_trimmed/b6_raw/b6_std)，
  若还要跑 STEP 5b 须保留，只删 `--mode normal` 那批 → 用 `prep_fakeavceleb.py --mode normal` 重抽。
- 云端重抽必须内联全套 env：`HF_HOME=/root/autodl-tmp/SyncX/hfcache HF_HUB_OFFLINE=1
  TRANSFORMERS_OFFLINE=1 SYNCX_MEDIAPIPE_GPU=0 SYNCX_DEVICE=cuda
  PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`；漏了 HF_HOME 会触发 CLIP 联网下载→Errno 99 卡死。
  （HF 缓存路径在 /root/autodl-tmp/SyncX/hfcache，非默认 ~/.cache/huggingface，已在 cloud_settle 三个 .sh 确认。）
- 提速：瓶颈在 MediaPipe 唇形(CPU,每 clip 新建检测器)。当前 GPU 0% 空闲、CPU 只用 ~10.8/16 核。
  加并行到 8 路安全，16 路显存/轨迹风险高不建议。**MediaPipe CPU 是慢头，不是核数**。

**归因框架（重抽结果出来后对照判读）**：
- 若 HiFi/DFE 重抽后**明显回升**（HiFi>0.4834，尤其 DFE 看是否再涨）→ 实锤"时间窗错位"是跨域崩的
  **机械主因**，方向B + 对齐后可成立，修复具决定性。
- 若**只 HiFi/DFE 微动、FakeAV 不变** → 错位是必要非充分，仍需回到模型（方向B h_long 负迁移 / 监督）。

**待验证产物**：`prep_hifi.py / prep_eval2024.py / prep_fakeavceleb.py / prep_diffusion.py` 已改为
训练域同款中心 4s 窗对齐；重抽 3 评测集 cache 用已有方向B ckpt 重测（纯数据层替换，不重训权重）。
结果落 jsonl 后可回填到 §1 首表。

## 8H. 【窗口对齐假设被实测证伪，归因回到模型层】2026-08-22

**执行**：改 4 个跨域 prep 为训练域同款"中心 4s 窗音画对齐"，重抽 HiFi 全量 cache（12 路，目标 3810），
用**同一方向B ckpt（syncx_best_seed0.pt）** 重测 HiFi——纯数据层替换、不重训权重、单变量。

**重抽落地**：cache 0 → 3787（接近 3810），12 路全 `Done`，`manifest_shard*.jsonl` 各片落盘。
云端重抽踩坑（已在 §8G 预判并复现）：CLIP 联网 Errno99 → 需内联 `HF_HOME=/root/autodl-tmp/SyncX/hfcache`
+ `HF_HUB_OFFLINE=1`；8→12 路提速（CPU 16 核，GPU 显存富余 24G）。

**决定性结果（对 §8G 归因框架的直接回答）：**

| HiFi-AVDF | AUC | 判读 |
|-----------|-----|------|
| 方向B（**错位特征**，§8D）| 0.4834 | — |
| 方向B（**窗口对齐**，本轮）| **0.4887** | **仅 +0.005，仍贴地(≈随机)** |

**定论：窗口对齐假设证伪，特征抽取（含时间窗）不是 HiFi 崩的主因。**
- 修复了"视频整段 vs 音频前4s"的机械错位后，HiFi AUC 仅 0.4834→0.4887（+1.1%，两版本都在随机线附近，
  非噪声级回升）→ **跨域评测集 prep 抽没「抽好对齐」确实是坑，但坑不是 HiFi 贴地的决定性原因**。
- 这条把"特征没抽好"的直觉**实测证伪**，价值在于**排除一个预设根因**，把定位**精确收敛回模型/监督层**。

**交叉佐证（三组一致）**：
1. §8E：关 sync 反降（0.4834→0.4735），sync_t 探针 HiFi≈随机(0.580) → 软肋在 h_long，不在 sync、也不在特征对齐。
2. §6B/§7：训练域 DeepSpeak 健康（全零仅 ~1%，音频 199 帧统一），非训练集抽错。
3. §8C：训练配方轴三连负，归因上移"瓶颈在离线特征表征层跨生成器不可迁移"——本轮实测与之一致：
   **对齐只是必要条件，非充分；HiFi 的负迁移在模型层（LTCA h_long 骨干），不在地上数据层。**

**归因结论（合并 §8E 定格）**：方向B 在 HiFi 的软肋 = **LTCA 的 h_long 长时内容骨干把 DeepSpeak 域专属
时序指纹带进来，在 HiFi（Sora2/Veo3.1 等端到端一体生成、lip-sync 高度成熟）上不迁移甚至反向**。
窗口对齐修不回来。DFE 增益（0.5796）同样是 h_long 在 DFE 有效、FakeAV 守 0.60——方向B 维持「部分成立：
DFE 可迁移增益成立、HiFi 贴地为模型层软肋」的诚实结论。

**去向（§10 导向，二选一，不需再抽特征）**：
- **收敛写论文**：方向B 呈现"DFE 首次>0.55 + FakeAV 守 0.60、HiFi 真实贴地为最严苛集水平（业界同集多≈随机）"，
  如实不加饰。
- **模型层再动**：给 h_long 加跨域正则 / 一致性先验（ROGA 式，§8F 立项）重训 Stage-2——这会动权重，
  需删 `.resume`/`.markers`（见工程红线），是下一轮可选方向。

## 10. 判读口径（防再踩）

- 不平衡集（FakeAVCeleb 等）只信 **AUC**，不信 AP/ACC。
- `strength=max(auc,1-auc)`；`cohen_d` 符号变化 = 非物理不变（生成器专属）。
- `--mask audio`=保留视觉；`--mask visual`=保留听觉（易反，项目内统一此语义）。
- 跨域判读只看 DFE2024 / HiFi（干净、近乎平衡），FakeAVCeleb 仅作参考。

### 11.2 类比（便于向导师口头展开）

三个病人：DFE 好转、FakeAV 守稳、HiFi 没救。价值不在"三个都治好"，
而在**精确查明第三个为何治不好**（h_long 骨干把训练域时序指纹带进跨域、不迁移），
且**排除了一批假根因**（非数据对齐、非 sync 标量、非冻结策略）。这份病历本身就是贡献。

### 11.3 论文收尾叙事建议

- **标题方向**：基于音画一致性的跨域深度伪造检测——部分可迁移增益与域过拟合的机制分析。
- **三块已成**：① 正向结果（LTCA 在 DFE2024 实现首次可迁移增益）；② 负结果+机制（HiFi 贴地 =
  h_long 域专属指纹，有证据链非猜测）；③ 方法论（捷径扫描 + 单变量归因流程，可复用）。
- **是否"过拟合"口径**（§8C 曾用"结构性过拟合"，对外更精确说法）：**不是经典过拟合**（同域验证仍高，
  0.9758/0.9462），而是**域过拟合/捷径学习**——训练域生成器专属判别特征跨生成器不迁移。比经典更难治：
  加同域数据无效，须从模型/特征层动刀。
- 硕士/博资论文不需 SOTA，需"清楚问题 + 可复现实验 + 诚实分析 + 可解释结论"，四者现均具备。

### 11.4 尚未打出的牌（勿提前判死）

`diag_real_prior.py`（真实一致先验探针）2026-08-28 实测结果（Vox/DeepSpeak/HiFi 三源共 600×2=1200 fake + 1800 real 统计）：

| 统计量 | 全局 auc(实0更高) | strength | 跨集漂移判定 |
|--------|-------------------|----------|--------------|
| corr_pre（L_corr 一致性） | 0.348 | 0.652 | ❌ **方向反：模型中真实一致性均值 < 生成** |
| corr_sync（LTCA 逐帧一致性） | 0.544 | 0.544 | ❌ **漂移 ≥ 差距：真实跨源漂移 ≥ 真实/fake 差距** |
| sync_std（一致性稳定性） | 0.603 | 0.603 | ❌ **漂移 ≥ 差距：同上** |

**最终判定（严格按 §10 判读）**：
1. 三个统计量全部不满足"强可分+漂移<差距"。真实一致性信号在模型里**不具备跨生成器可迁移性**；
2. 即便是唯一 strength ≈ 0.65 的 corr_pre，**方向直接和假设相反**（模型学到"生成一致性更高"）；
3. 原因：一致性信号本身在真实域不同源之间波动比"真实-fake 差距"还大——真实一致性先验无法作为跨生成器不变量。

**结论（升级版，与 §12 关键区分一致）**：真实一致性先验在**当前离线冻结特征框架、跨模态余弦定义**下被证伪，不可作为跨源不变量。**但"证伪的是特征框架、非方向本身"——端到端对齐微调（HAVIC/X-AVDT 式）能否让一致性可迁移，尚未验证**。当前方向B 的"DFE 首破 0.55 + FakeAV 守稳、HiFi 贴地"是冻结框架下的诚实终点；是否在此收笔视 §12 的端到端试点再定。

## 12. 奔波关键区分：证伪的是「特征框架」，不是「方向本身」（2026-08-28）

> 起因：探针三统计量全负后，一度以"方向判死、没法了"仓促定性。本节澄清一个被漏掉的关键区分，
> 纠正向社区的"证伪有价值"误被当成"自己硕士没结果"。**这决定下一步是否还有值得做的方向。**

### 12.1 "证伪有价值"是什么意思（先说清，避免误当安慰）

- 科学的"证伪有价值"，是面向**社区**的：Michelson–Morley 测不到"以太"，反而证实"以太不存在"、
  催生相对论。同理，你用系统实验测出"在这套模型下一致性不可分离"，能给后来者"别在此烧 GPU"的信息。
- **但硕士要的不是"证伪一个假设"，是要"可交付成果"。** 除非证伪本身够深够完整，否则"我证伪了、
  没做出来"单独不能成文。所以"咋办"是正问——**你要的是成果，不是验证。**

### 12.2 关键区分：你测的"不可分离"，可能被「特征框架」困住了

- 你的探针在**离线特征（CLIP/wav2vec2 完全冻结）**前提下测——模型只学残差、特征锁死不随"一致性先验目标"变。
- 而 HAVIC / X-AVDT 之所以有效，恰恰是**端到端学了音画对齐**：它们的特征随"对齐目标"一起被学出来，
  一致性是可**索取**、可不断被压向可分的状态。
- 用**冻结老钥匙**去复验一个**需要重新配钥匙**的先验，等价于用锁死的老钥匙开锁——打不开是"钥匙"的问题，
  不是"锁（方向）"的问题。

**因此准确结论是**："在**离线冻结特征**下，一致先验不可迁移"——**证伪的是特征框架，不是一致先验方向。**

### 12.3 三种可能（诚实排序）

1. **直接收笔**：保住时间线。不稳的是"带没问题的将就收笔"。
2. **端到端对齐微调试点（推荐，廉价高信息）**：只看一致性先验是否因"冻结特征"才测不到——阳性则方向B
   故事从"DFE破0.55+HiFi贴地+先验证伪"升级为"一致性先验在端到端对齐下可迁移，之前不可测是冻结特征所致"；
   阴性才真收笔。代价约几小时~1天 GPU。
3. **系统性负结果成文**：把结论写成"跨域深伪检测的一个系统负结果"（不骗自己、不空手）。

**§13 按下述方式 2 设计试点，需用户确认 GPU 预算后执行。**

## 13. 系统方案设计 · 端到端音画对齐微调试点（2026-08-28）

> 目标：用一个**廉价但信息量饱和**的试点，判定"一致性先验不可迁移"是否因**离线冻结特征**造成，
> 而非方向本身。为不浪费 GPU，设计成**一组可证伪、可区分两种解释的单变量实验**。

### 13.1 科学问题（先定死可证伪口径）

- H0（被§11.4探针支持）：真实一致性先验在模型前向下……不论怎么征学都不迁移 → 方向死，收笔。
- H1（本试点想证明）：真实一致性先验**在端到端对齐学出的表征下可分离** → 之前测不到是冻结特征所致，
  方向B 可再生。→ 值得重训/换表征。

**判死/复活闸门**（对标 §10）：端到端试点模型的三个一致性统计量，在**新鲜跨域源**上须同时满足
- ① corr_pre/corr_sync 的 within-set auc(实0更高) ≥ 0.65（real 一致性显著更高，方向对）；
- ② 真实跨源漂移 < real/fake 差距（可迁移）；
- 若 ①② 对两个不同跨域源（DFE2024、HiFi）都成立 → H1 成立，方向B 从"冻结框架死局"中被救出。
- 若至少一个不满足 → H1 被否，确认这是综合框架（不只特征）的问题，收笔。

### 13.2 方案主体（单变量，一次只脱一个"冻结"）

**端到端对齐微调（对齐 HAVIC/X-AVDT 范式，但保持项目最小改动）**：

- **放开**：Stage-2 微调时**不冻结** LCMA audio/visual 投影 + 主干（不再是 FREEZE，取 §8D 全量微调基线上加新目标）；
- **新增监督（一致性先验目标，替代/补强 L_sync）**：在真实段上，用**对齐目标**显式压
  `cos(a_lcma, v_lcma) → 1`（跨模态逐帧对齐），让特征随"真实一致性"被学出来——这是冻结框架下唯一缺的环节；
- **其余不变**（冻结 wav2vec2/CLIP 离线特征、同一 DeepSpeak 训练集、同一 ckpt 初始化），保证是"加端到端对齐"这**唯一**变量。

**对照组设计（单变量归因，防把"加对齐"和"放下冻结"混在一锅）**：
| 组 | 微调 | 对齐目标 | 判读 |
|----|------|----------|------|
| A（基线，已有 §8D）| 全量微调 | 无显式对齐 | HiFi 贴地，作归零参照 |
| B（本试点）| 全量微调 + 不冻结视觉投影 | 显式跨模态对齐 L_align | 若 HiFi 可分离 → H1 成立 |
| C（可选控制）| 全量微调 + 不冻结视觉投影 | 无显式对齐（仅靠分类隐式）| 区分"是放开了投影"还是"是加了对齐" |

### 13.3 最小改动点（对齐现有代码，不引入新框架）

- `losses.py`：新增 `AlignmentPriorLoss`——对 real 段压 `1 - cos(a_lcma, v_lcma)` 至 0（对应 L_corr 的
  real_only 口径，但作用在**逐帧 content 嵌入**而非 pooled 投影），权重 λ_align 走 config 新增项。
- `train_stage2.py`：`cfg.fta_enabled=1` 基础上，新增 `SYNCX_ALIGN_LOSS`（开关）+ `SYNCX_ALIGN_WEIGHT`；
  仅对 real 段施加。`SYNCX_FREEZE` 保持 0（不冻结）= B 组；可选 `SYNCX_FREEZE_VISUAL_ONLY=0` 控制是否放开视觉投影。
- `config.py`：`align_loss (bool, def False)`、`align_weight (float, def 0.1)`、`align_on='real'`。
- `smoke_fta.py` 加一例 `align_loss=True` 的形状/梯度冒烟，交叉验证 L_align 接入不崩。

### 13.4 运行（云端，沿用所有工程红线）

```bash
# 必须先删方向B旧续跑点，否则 strict 加载旧架构崩（见工程红线）
rm -f /root/autodl-tmp/SyncX/persist/ckpt/syncx_best_seed0.resume \
      /root/autodl-tmp/SyncX/persist/.markers/*.done
# 端到端对齐微调 B 组：全部内联
SYNCX_FTA=1 DIRECT_B=1 \
SYNCX_ALIGN_LOSS=1 SYNCX_ALIGN_WEIGHT=0.1 \
SYNCX_FREEZE=0 SYNCX_COMPILE=0 \
HF_HOME=/root/autodl-tmp/SyncX/hfcache HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
SYNCX_MEDIAPIPE_GPU=0 SYNCX_DEVICE=cuda \
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
bash cloud_settle_all_mvp.sh
```

### 13.5 判读与止损

- 中途每 epoch 看 train 域 val：若对齐目标把 val_auc 压崩（<0.90）或数值发散 → **早停止损，判 H1 否**，
  没必要训满 80 epoch——一个收敛性信号足以。
- 训练完成 → §11.4 同款 `diag_real_prior.py` 全量重测，严格按 13.1 闸门判定。
- 若 H1 成立（闸门过）→ 方向B 可续，进入"一致性对齐 + LTCA 长时"合并版重训（下一阶段）；
  若 H1 否 → 收笔，§11.3 叙事直接可用。

### 13.6 预算估计与风险

- 预算：全量微调 80 epoch 在 RTX 4090D / 24G 上已有基线（数小时级）；本试点理论同量级，约 **0.5–1 天**。
- 风险：加了显式对齐目标可能和现有 L_corr/AAM 在同一 audio_emb 上反向拉扯（§8E 已见 sync 类目标对
  HiFi 微反）。对策：L_align 作用在 content 嵌入、λ 走 0.1 起步、以 C 组区分"何者改良"。
- 决策点：**此试点是否执行，取决于用户给到 GPU 预算（见第一步）**。

## 13b. 【§13 试点实测：B组端到端对齐 = "跷跷板负迁移"，未复活方向】2026-08-28

**执行**：接 §13 方案，仅跑 **B 组**（全量微调 + 显式逐帧对齐监督 L_align_prior，λ=0.1，
40 epoch，batch 512，DeepSpeak train 训）。复用了既有特征（不重抽）、既有 Stage-1
（复用 $STAGE1_CKPT），输出独立 ckpt `alignprior_groupB_best_seed0.pt`（不覆盖主管线）。
Epoch 日志确认 `align_prior` 损失 0.30→0.08 收敛、val_auc 0.44→0.95，训练域内部健康。

**中途发现（诚实记账）**：DFE2024 的跨域评测缓存此前缺失（`prep/test` 下 cache 为 0，
历史 DFE 数字走的是旧缓存路径）。为补 B 组判定，16 路并行重抽 DFE2024 test，得 728 个
cache（目标~815，少 87 个为正常跳过失败视频），随后用 `--eval_cache .../prep/test` 评测。
FakeAV/HiFi 两集用同一 ckpt 手动评测得到最终数字。

**决定性结果（同一 B 组 ckpt，三集对照 §8D 方向B·旧ckpt）**：

| 跨域集 | §8D 旧 ckpt（方向B·无对齐）| B 组（端到端对齐 λ=0.1）| 变化 |
|--------|------------|----------------------|------|
| FakeAVCeleb | 0.6009 | **0.5999** | ≈持平 (−0.001) |
| DFE2024 | 0.5796 | **0.5351** | **−0.045 ▼ 倒退** |
| HiFi-AVDF | 0.4834 | **0.5097** | **+0.026 ↑ 回升** |

**判读（对照 §13.5 闸门：DFE+HiFi 均须≥0.65 且真实跨源稳定才判复活）**：
- **DFE 0.5351**：自 0.5796 倒退 −0.045，远低于 0.65 → **未复活**。
- **HiFi 0.5097**：自 0.4834 回升 +0.026（离开贴地的“越测越低”），但对 0.65 仍贴地 → **未达标**。
- **合并**：端到端对齐是**「拆东墙补西墙」=跷跷板**——救了 HiFi 的反向，却赔了 DFE 的增益；
  **不是跨域可迁移**。它只是把一致性往 DeepSpeak 训练域方向拧，帮助了结构较近的 HiFi、
  损害了结构更远的 DFE。这从实测端独立地**支持 §6B 的判死**：在这一特征框架下，
  **一致性先验无法成为跨生成器不变量**。

**为什么这是"有价值的负结果"而非"没救"（升华点，写进论文）**：
- 跷跷板本身证明：**一致性信号确实被模型捕到了也在用**（否则不会一头升一头降），
  但它**没有成为跨域不变量**。→ 论文可写为"单一来源（DeepSpeak）监督下，
  端到端对齐导致的负迁移机制"，供多域联合/域不变对齐（ROGA 式、HAVIC 蓝图）后续承接。
- 与 §12 交底一致：证伪的依然是“**该离线特征框架 + 单源监督**”下的可迁移性，
  **并未**宣称“一致性方向在理论/多源设置下不可能”。界线画在这里。

**去向（决策点，留给用户）：**
- 收笔方向：按此“部分成立（FakeAV 守 0.60 / DFE 曾>0.55）+ 跷跷板负迁移机制”写论文 negative-with-mechanism。
- 若仍不甘心，唯一未试的是“多域联合对齐 / 域不变正则（ROGA 式）”那种把一致性同时对齐到多源
  ——那是另一量级工程，且当前证据未显示值得（单源都保不住两域）。

## 14. 【§13b 之后 · 补全 HAVIC 三层一致性先验的实测=复现失效，诚实否定】2026-08-28

**起因**：§13b 端到端对齐只补了"对齐目标"，诱因是"一致性先验没做全"（HAVIC 三层只用了
InfoNCE 对齐、漏了 reconstruction 的结构层）。本节把 HAVIC 式三层补全（掩码跨模态重建 +
全局语义交叉重建，Stage-1 纯真实数据），看能否把"真实一致性"压成跨生成器不变——红线命题的最后一块拼图。

**执行**：`SYNCX_HAVIC_RECON=1` 在 Stage-1 纯真实 VoxCeleb2 上增加两条跨模态自监督：
§14-① `MaskedCrossReconLoss`（mask 一模态部分时间 token、用另一模态逐帧重建）+ `CrossSemanticReconLoss`（全局语义交叉重建）。
Stage-1 训 **60 epoch**（与 baseline 一致，见下方 kin 里程碑记录），Stage-2 走与基线同配方（`SYNCX_FTA=1`、
无显式对齐），输出独立 ckpt `stage1_havic.pt → syncx_havic_best_seed0.pt`，不覆盖主管线。
三跨域评测用对比脚本 `cloud_settle_havic.sh` 同管线评估（baseline 用只读 `syncx_best_seed0.pt` 的 `baseline_ref` 重评为基础）。

**机制确认（排除"实现没生效"退路）**：训练日志确认 `hav_mask`/`hav_sem` 随轮次单调降到 ~1e-3、
`infonce` 正常收敛，重建目标真实进入反向传播 → 本版不是死代码（对比 2026-08-28 早些时候的 bug 版），
三层先验**确实装上并训满**。

**决定性结果（HAVIC 60ep vs 同管线 baseline_ref）**：

| 跨域集 | HAVIC(AUC) | baseline_ref(AUC) | Δ | 判据(≥0.65 &高于) |
|--------|-----------|-------------------|----|--------------------|
| DFE2024 | **0.5081** | **0.5585** | **−0.050 ▼** | ✗ |
| HiFi-AVDF | **0.4933** | **0.4887** | +0.005（噪声级）| ✗ |
| FakeAVCeleb | 0.5643 | 0.6009 | −0.037 | 域内无提升（仅参考）|

**判读（严格按 §10/§13.1 闸门：DFE 且 HiFi 均须 ≥0.65 且高于 baseline 才判复活）**：
- **不达标**：DFE 较同管线 baseline 倒退 −0.050，HiFi 仅 +0.005 噪声级，两集都远低于 0.65 → **方向未复活**。
- **归因**：补全 HAVIC 三层（重建 + 语义交叉）在"离线冻结 CLIP/wav2vec2 载体 + 单源 DeepSpeak 监督"下，
  仍不能把真实一致性压成跨生成器不变量 → **与 §13b 跷跷板、§11.4 探针、§8D/8E LTCA 五条证据共同指向同一根因**。
- **HAVIC 三层补全这一具体 implement 被证伪**（不是"没做全"导致的退回）：三层齐上、训满、单变量，仍复现失效。

**本节的附加学习（供后续复用，非论文）**：
- **Stage-1 至少 60 epoch，kin 晚熟**：baseline 日志显示 `kin` 前 ≤30 epoch 钉死 ln(2)=0.6931（随机），
  成功的那几次都在 **ep30 之后才骤降**（0.95→0.05）；早期 HAVIC 40ep 版本 kin 只到 ~0.4 属半完成。
  → 凡涉及 Stage-1 预训练的对照，一律用 60 epoch，否则破坏单变量。
- **exp_id 不含 HAVIC 参数 → Stage-1 日志与 baseline 混写**（`syncx_bs512_lam0.3_lacaboth_seed0/stage1_train.jsonl`），

## 15. 【多源路线必要前置探针：跨生成器符号稳定性 = 失败，多源不投卡】2026-08-28

**起因**：§14 关掉 HAVIC 后，唯一未试的改根因前提方向 = 多生成器/多域一致性联合训练 + 域不变
正则（ROGA 式，§8F 老立项）。§14 去向把它列为"是否投入"的决策点。本节先用**廉价探针**
（不重训、只跑现有 ckpt + 盘上缓存）测其**必要前置**：一致性信号是否跨生成器**符号稳定可分离**。
不满足 → 多源监督没有"一致目标可学"，不值得烧重训。

**探针**（新交付物 `diag_multigen_prior.py`）：复用 `diag_real_prior.per_clip_stats`（corr_pre /
corr_sync / sync_std，模型现有前向、无新参数、非拟合），把每集 fake 按**单个生成器**分组，
逐组算 real-vs-该生成器 的 AUC/cohen_d，再跨所有生成器统计**符号一致性**。判据跑前定死：
≥2 个生成器组同符号 strength≥0.6 且大多数组方向一致 → POSITIVE(值得多源重训)，否则 NEGATIVE。

**分组有效性（可信性前置，先核对后统计）**：
- **HiFi 分组有效**：`identity=生成器`（`prep_hifi.py` 对全部分片写入 generator 名），6 个商用
  生成器组各带 real/fake，且 real/fake 同处目录内 → 同生成器下 real-vs-fake，隔离生成器残差，干净。
- **DFE2024 分组无效，原则性排除**：`prep_eval2024.py` 写 `identity=文件名`=随机 YouTube ID，权威
  CSV 仅含 real/fake、**无生成器标注** → DFE2024 数据层面无法生成器分组。诚实处置：不参与多生成器
  判定，并明确记录原因（不打擦边球强行分组）。

**决定性结果（HiFi 6 个 SOTA 商用生成器，real/fake 各 ~226–394/组）**：

| 统计量 | 符号分布(+ = real 更一致/更稳) | 强可分(≥0.6) 组数 | 判定 |
|--------|-------------------------------|-------------------|------|
| corr_pre  | **+3 / −3**                       | 1（pixverseV5 0.608）| **无一致目标** |
| corr_sync | **0 / −6**                        | 2（sora2 0.673 / wan2.5 0.608）| 方向稳定但负、强度弱 |
| sync_std  | 0 / −6                            | 0                    | ≈随机 |

代表数字（corr_pre 各生成器 auc 实0）：kling2.5 0.572 / pixverseV5 **0.608** / seedance1.0 0.532 /
sora2 0.534 / veo3.1 0.458 / wan2.5 0.480；corr_sync：sora2 0.327(strength 0.673)、wan2.5 0.392(0.608)、
其余 ~0.44–0.49。

**判读（闸门 NEGATIVE，诚实计量）**：
- **corr_pre +3/−3 = 决定性负信号**：真实一致性相对生成器是"条件性的"，被 6 个生成器劈成两半 →
  **直接证伪"真实一致性更高"是跨生成器不变量** → 多源监督要压的这个量，跨生成器没有一致方向可学。
- **corr_sync/sync_std 全负的诚实保留**：6/6 同号非纯噪声（符号检验 p≈0.03），模型确实捕获到
  方向稳定的量，但**方向与 HAVIC 假设相反、强度偏弱**（均值 ~0.57）；且"sync 负"在 §8E 已记录。
  它不支持"真实更一致"的多源目标，闸门判负成立；但**不可夸大**为"毫无信号"。
- **净判定**：多源一致性先验在现有单源对齐下，跨生成器无一致强目标 → **不投重训卡**。

**与既有证据自洽（§15 → 五条独立证据统一收口）**：§11.4 探针（真实一致性跨源漂移≥差距）、
§8D/8E（LTCA h_long 单源时序指纹负迁移）、§13b（端到端对齐跷跷板）、§14（HAVIC 三层重建复现失效）、
§15（多源必要前置失败）——**五条全部指向**：在"离线冻结 CLIP/wav2vec2 载体 + 单一源监督"这一框架下，
音画一致性无法成为跨生成器不变量；改成多源也无法凭空造出（必要前置已否）。

**去向（§15 关闭"改根因前提"的廉价验证，留下真决策）**：多源必要前置失败 → 剩余选项收敛为：
① 换"真实音画联合预训练"载体（HAVIC 配方，需新骨干，风险高）—— 只在用户愿为新骨干投入时再议；
② 接受框架边界，按 §11.3 诚实叙事收稿（DFE 首破 0.55 正向 + 跷跷板负迁移机制 + 五条完整诊断链为方法论贡献）。
③ 系统性负结果成文。**此三选一是决策事项，由用户根据剩余预算/时间定夺；§14/§15 均已如实记录在先，可随时退底。**

## 17. 【GenD 组件消融：Rec B / Rec C 均无可复现跨域增益】2026-09-07

> 触发点：主配置（满 $GenD$）在 §16 载体探针后仍是被最看好的一条跨域机制（Rec B 超球面度量

> Rec B / Rec C 两组单变量消融，验证该机制是否真的贡献跨域泛化，还是又一个训练域专属捷径。

### 17.1 实验设置（单变量，严格对齐主配置）

三套变体：**主配置（Rec B + Rec C）**、**w/o Rec B**（$\lambda_{\text{align}}=\lambda_{\text{uniform}}=0$）、
**w/o Rec C**（回退标准 i.i.d. 采样）。控制项两侧完全一致：同一 $FTA$/$LTCA$ 架构、batch 512、
lr $1\times10^{-4}$、80~epoch 早停，各跑 3 个随机种子，均在各自验证集最优检查点上评测。

`same_source_sampling` 硬编码 `True`，无开关）——这是实现前置，不改主配置行为。

### 17.3 判读（严格按 §10 口径）

### 18.5 工程坑（重跑前必读）

1. **必须 `SYNCX_COMPILE=0`**：容器内 `torch.compile(mode=max-autotune)` 在 cudagraph 内存池
   必崩（`torch/_inductor/cudagraph_trees.py` → `_cuda_setCheckpointPoolState` 抛
   `Expected curr_block->next == nullptr to be true, but got false`）。编译只影响速度，关掉无副作用。
2. **`--disable_lcma` 维度 bug**（已修，`models.py`）：关 LCMA 时 `audio_emb`(2d=512) 喂给
   `audio_aam`(d=256) → 第一步即崩。修法：新增 `audio_emb_head` 仅给音频分类头用。
3. **`laca_mode=biomech` 必崩**（已修，`train_stage2.py`）：corr 支路关闭时
   `k_shared/a_shared=None`，原代码无条件 `.float()` → 加 None 判断置 0。
4. **禁止 `nohup bash -c '...'` 套娃启动**：曾出现 3 条训练链写同一 `--out_ckpt`/`--exp_id`/日志，
   互相覆盖。应直接 `PYTHONUNBUFFERED=1 nohup python run_module_ablation.py ... &`。
5. **`append_jsonl_dedup` 去重键为 `("epoch","phase")`**：旧 jsonl 未删就重跑会静默跳过新行
   （进度永不更新）→ 重跑前必须删 `logs/<eid>/stage2_train.jsonl`。
6. **进程判断用 `pgrep -af`**，勿用 `ps aux | grep`（管道截断命令行导致假阴性）。
